# 안심 지킴이

프로젝트를 시작하기 전에 [docs/SETUP.md](docs/SETUP.md)를 먼저 읽으세요.

## 프로젝트 개요
- 한 줄 소개: 사기 문자는 받는 순간 알려 주고, 모르는 건 말로 물으면 노란 테두리로 알려 주고, 키오스크는 미리 연습하는 어르신 스마트폰 도우미 웹앱(PWA) (개발 중)
- 누구를 위한 앱인가: 스마트폰 사기 문자와 낯선 화면·무인기가 어려운 어르신, 그리고 어르신을 돌보는 가족(보호자)
- 어떤 상황에서 쓰는가: 택배·가족 사칭·정부 지원금 같은 의심 문자나 QR 코드를 받았을 때, "사진 보내기"처럼 휴대폰 사용법을 모를 때, 음식점·병원·기차역 무인기를 쓰기 전에 연습하고 싶을 때

## 주요 기능
| 과제의 꼭 있어야 하는 기능 | 화면(프론트엔드) | API(백엔드) |
| --- | --- | --- |
| 1. 문자 지킴이 — 가상 휴대폰을 쓰다가 체험 문자가 도착하는 순간 학습 AI가 채점해 위험도별 경고 팝업(링크 차단·앱 설치 가리기 연출), 받은 문자·카톡을 붙여 넣거나 [공유]로 검사, QR 코드 검사. 모든 검사는 기록으로 저장되고 "사기 맞아요/아니에요" 정답 알려 주기·메모 고치기·지우기 | `/check` (`src/app/(app)/check/`) | Server Action `createDemoScan`·`createMessageScan`·`createQrScan`·`updateScanVerdict`·`updateScanMemo`·`deleteScan` (`src/app/(app)/scan-actions.ts`), 채점 `src/lib/scan/analyze.ts`(규칙 `rules.ts` + 학습 AI `model.ts`) |
| 2. 말로 물어보기 — 마이크로 "사진 보내고 싶어요"라고 말하면 자유롭게 조작하는 가상 휴대폰(홈·메신저·문자·카메라·사진첩·설정·전화·시계 앱, ◁ 뒤로·▢ 홈)에서 지금 눌러야 할 곳에 노란 테두리로 한 단계씩 안내(다른 화면으로 가면 돌아오는 방법 안내, 소리로도 읽어 줌). 배움 노트 저장·목록·제목 고치기·지우기, 끝까지 연습하면 연습 횟수 증가 | `/ask` (`src/app/(app)/ask/`) | Server Action `saveNote`·`listNotes`·`renameNote`·`practiceNote`·`deleteNote` (`src/app/(app)/ask/actions.ts`) |
| 3. 키오스크 연습 — 음식점 주문·병원 접수·기차표 예매 무인기를 실제 순서대로 연습(틀리면 다시 안내, [도와주세요]로 노란 테두리 힌트). 걸린 시간·실수·막힌 단계를 연습 기록으로 저장, 메모 고치기·지우기 | `/kiosk` (`src/app/(app)/kiosk/`) | Server Action `saveSession`·`listSessions`·`updateSessionMemo`·`deleteSession` (`src/app/(app)/kiosk/actions.ts`) |

- 현재 상태: 화면·서버 처리·DB 모델을 만들고 타입 검사·린트·빌드를 확인했습니다. Supabase 프로젝트를 연결하기 전이라 실제 저장·로그인은 아직 확인하지 않았습니다.
- 로그인(이메일·비밀번호, Supabase Auth)해야 위 화면을 쓸 수 있고, 내 기록은 나만 보입니다(모든 서버 처리가 로그인 확인 → 입력 검증 → 내 자료인지 확인).
- 체험 문자는 시연·연습용으로 만든 가짜 문자입니다. 실제로 받은 문자는 붙여 넣기나 문자 앱의 [공유] → 안심 지킴이로 검사합니다.

더 만든 기능:
- 보호자·연락처 관리 — 가족·보호자 추가·고치기·지우기, 바로 전화 걸기 (`/contacts`)
- 나의 성장 — 세 기능의 기록(검사·배움 노트·키오스크 연습)을 모아 보여 주는 홈 화면 (`/home`)
- PWA — 홈 화면에 설치, 문자 앱에서 [공유]로 바로 검사 (`src/app/manifest.ts`, `public/sw.js`)

## 기술 스택
- 프론트엔드: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Zod(입력 규칙), 브라우저 내장 QR 인식(BarcodeDetector)
- 백엔드: Next.js Server Action, Prisma 7 (`@prisma/adapter-pg`), Supabase Auth (`@supabase/ssr`) 로그인, `src/proxy.ts`에서 로그인 세션 갱신·보호된 화면 접근 차단
- 데이터(어디에, 무엇을): Supabase PostgreSQL (`prisma/schema.prisma`) — `users`(회원, Supabase Auth 사용자 id), `scan_records`(메시지·QR 검사 기록: 내용·위험도·이유·메모), `contacts`(보호자·연락처), `guide_notes`(배움 노트), `kiosk_sessions`(키오스크 연습 기록)

## 실행 방법
<!-- 처음 보는 사람이 그대로 따라 할 수 있게 쓴다. 시작 저장소 그대로라면: npm install → npm run dev → 브라우저에서 http://localhost:3000 -->
1. Node.js 24를 설치하고 저장소를 내려받은 뒤 `npm install`을 실행합니다.
2. `.env.example`을 `.env`로 복사하고 Supabase 값을 넣습니다. 자세한 방법은 [docs/SUPABASE_SETUP.md](docs/SUPABASE_SETUP.md)를 참고합니다.
   - `DATABASE_URL`(Transaction pooler, 6543), `DIRECT_URL`(Session pooler, 5432)
   - `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`(공개 키만 — secret 키는 넣지 않음)
   - Supabase → Authentication → Sign In / Providers에서 이메일 확인(Confirm email)을 끕니다(가입 후 바로 로그인).
   - (DB 마이그레이션 적용 방법은 마이그레이션을 만든 뒤 추가합니다.)
3. `npm run dev`를 실행하고 브라우저에서 http://localhost:3000 을 엽니다.

배포 주소(있으면): 아직 없음 (Vercel 배포 예정)
