# 안심 지킴이

프로젝트를 시작하기 전에 [docs/SETUP.md](docs/SETUP.md)를 먼저 읽으세요.

## 프로젝트 개요
- 한 줄 소개: 어르신에게 오는 스미싱(문자 사기)을 받는 순간 감지해 막고, QR 코드와 받은 문자를 학습된 AI가 검사하는 스미싱 차단 웹앱(PWA) (개발 중)
- 누구를 위한 앱인가: 스마트폰 사기 문자에 취약한 어르신과, 어르신을 돌보는 가족(보호자)
- 어떤 상황에서 쓰는가: 택배·가족 사칭·정부 지원금 같은 의심 문자나 카톡을 받았을 때, 전단지·우편물의 QR 코드를 찍기 전에, 받은 문자가 사기인지 확인하고 싶을 때

## 주요 기능
| 과제의 꼭 있어야 하는 기능 | 화면(프론트엔드) | API(백엔드) |
| --- | --- | --- |
| 1. 실시간 문자 인식·감지·차단 — 가상 휴대폰을 쓰다가 문자·카톡이 도착하는 순간 학습 AI가 채점해 위험도별 경고 팝업을 띄우고, 문자 속 위험한 링크를 누르면 사이트를 막고 앱 설치 화면을 가림. 감지 결과는 검사 기록으로 저장되고 "사기 맞아요/아니에요" 정답 알려 주기·메모 고치기·지우기 | `/check` 실시간 감지 탭 (`src/app/(app)/check/demo-phone.tsx`), 가상 휴대폰 `src/lib/phone/engine.ts` | Server Action `createDemoScan`·`updateScanVerdict`·`updateScanMemo`·`deleteScan` (`src/app/(app)/scan-actions.ts`), 채점 `src/lib/scan/analyze.ts` |
| 2. QR 감지 — 카메라로 QR 코드를 찍으면 주소를 열지 않고 먼저 검사(단축 주소·수상한 도메인·http·앱 설치 파일 등)해 기록으로 저장, 카메라가 안 되면 직접 입력. 메모 고치기·지우기 | `/check` QR 검사 탭 (`src/app/(app)/check/QrScanner.tsx`) | Server Action `createQrScan`·`updateScanMemo`·`deleteScan` (`src/app/(app)/scan-actions.ts`), 판별 `src/lib/scan/rules.ts` |
| 3. 붙여 넣은 문자의 AI 판단 — 받은 문자를 복사해 붙여 넣으면(또는 문자 앱의 [공유]로 보내면) 학습된 AI가 스미싱인지 판단해 위험도·점수·이유를 보여 주고 기록으로 저장. 사용자가 알려 준 정답을 학습 데이터에 더해 그 사람에게 맞춰 판단 | `/check` 붙여 넣기 탭 (`src/app/(app)/check/MessageCheckForm.tsx`) | Server Action `createMessageScan`·`updateScanVerdict`·`updateScanMemo`·`deleteScan` (`src/app/(app)/scan-actions.ts`), 학습 AI `src/lib/scan/model.ts`·학습 데이터 `src/lib/scan/dataset.ts` |

- 현재 상태: 화면·서버 처리·DB 모델을 만들고 타입 검사·린트·빌드를 확인했습니다. Supabase 프로젝트를 연결하기 전이라 실제 저장·로그인은 아직 확인하지 않았습니다.
- 로그인(이메일·비밀번호, Supabase Auth)해야 위 화면을 쓸 수 있고, 내 기록은 나만 보입니다(모든 서버 처리가 로그인 확인 → 입력 검증 → 내 자료인지 확인).
- 웹앱은 휴대폰의 실제 문자함을 읽을 수 없어서, 1번은 체험용 문자가 가상 휴대폰에 도착하는 상황으로 보여 줍니다. 실제로 받은 문자는 3번(붙여 넣기·[공유])으로 검사합니다.

더 만든 기능:
- 보호자·연락처 관리 — 가족·보호자 추가·고치기·지우기, 바로 전화 걸기 (`/contacts`)
- 홈 요약 — 세 가지 검사 기록(전체·위험·QR·정답 알려 준 기록)을 모아 보여 주는 화면 (`/home`)
- 시뮬레이션 — 로그인 없이 가상 휴대폰에 설치된 앱으로 세 기능을 체험하는 미리보기 페이지. `npm run demo:build`로 `demo/dist/simulation.html`을 만든다 (`demo/`)
- PWA — 홈 화면에 설치, 문자 앱에서 [공유]로 바로 검사 (`src/app/manifest.ts`, `public/sw.js`)

## 기술 스택
- 프론트엔드: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Zod(입력 규칙), 브라우저 내장 QR 인식(BarcodeDetector)
- 백엔드: Next.js Server Action, Prisma 7 (`@prisma/adapter-pg`), Supabase Auth (`@supabase/ssr`) 로그인, `src/proxy.ts`에서 로그인 세션 갱신·보호된 화면 접근 차단
- 데이터(어디에, 무엇을): Supabase PostgreSQL (`prisma/schema.prisma`) — `users`(회원, Supabase Auth 사용자 id), `scan_records`(메시지·QR 검사 기록: 내용·위험도·이유·메모), `contacts`(보호자·연락처)

## 실행 방법

   - `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`(공개 키만 — secret 키는 넣지 않음)
   - Supabase → Authentication → Sign In / Providers에서 이메일 확인(Confirm email)을 끕니다(가입 후 바로 로그인).
   - (DB 마이그레이션 적용 방법은 마이그레이션을 만든 뒤 추가합니다.)
3. `npm run dev`를 실행하고 브라우저에서 http://localhost:3000 을 엽니다.
